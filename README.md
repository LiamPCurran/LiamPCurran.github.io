# liampcurran.github.io

Portfolio hub for Liam Curran: website fixes, speed, technical SEO and conversion copy.

Live: https://liampcurran.github.io/

Built by `build.py` (one static page, one self-hosted font, no frameworks) into `docs/`, which GitHub Pages serves. The case studies and writing samples are PDFs in `docs/files/`. Ashgrove, Tallyloop and Kettlepine are fictional concept projects.

Font: Plus Jakarta Sans (SIL Open Font License).
